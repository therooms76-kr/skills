**1차 판단 칸**

| 판단 | 뜻 |
|---|---|
| 채택 | 원래 모양 그대로 가져온다 |
| 변형 | 생각은 가져오되 모양·이름·범위를 바꾼다 |
| 나중에 | 필요하지만 지금은 아니다 (사람이 늘거나, 사업 단계가 오면) |
| 제외 | 우리에게 필요 없거나 해가 된다 |
| 고유 | 세 사이트에 없고 우리가 새로 만든다 |

**시기 칸**: 카페 = Phase 0~1 네이버 카페/디스코드에서 글 양식으로 먼저 시험 / v1 = Phase 2 웹 첫 버전 / 2단계 = v1 이후 / P3 = Phase 3 수익화 / — = 하지 않음

**판단 기준** (README와 같음): ① 로봇 회사와 싸우지 않는다 ② 일반인 5분 성공 ③ 경험은 이야기 ④ 사람이 적어도 돌아간다
