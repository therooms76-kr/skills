# 06. 화면 명세 — 웹 v1 (모바일 우선)

작성: 2026-10-18 (4단계) · 근거: [DECISIONS.md](DECISIONS.md) 1부(S1~S14)·2부(기능 검토), [04-skeleton.md](04-skeleton.md) v0.3

> 이 문서는 "어떤 화면이 있고, 각 화면에 무엇이 어떤 순서로 들어가며, 상황별로 어떻게 보이는가"를 적은 설계도입니다.
> 색·글꼴·모양은 정하지 않습니다 — 그건 5단계 디자인 의뢰서를 받은 디자인 시스템이 정합니다.
> 화면에 쓰는 말은 DECISIONS **S14 용어집**을 따릅니다 (팩, 해봤어요, 방, 넘어짐, 원본 위치 …).

---

## 0. 범위와 읽는 법

- **범위**: 사업계획서 Phase 2의 **웹 v1** (2027.4~9 목표). 카페 단계(Phase 0~1)에서 쓰는 글 양식은 같은 칸 구성을 따르되 별도 운영안에서 다룹니다.
- **기준 화면**: 폭 360px 휴대폰을 먼저 그리고(S13), 1024px 이상에서는 넓게 펼칩니다.
- **우선순위**
  - **P0** = v1 출시에 반드시 있어야 함 (핵심 흐름: 찾기 → 설치 → 해봤어요 → 묻기)
  - **P1** = v1에 들어가되 단순한 모양으로
  - **P2** = v1 이후 (자리만 비워 두지 않음 — 나중에 추가)
- **화면 ID**: `SCR-번호`, 운영 화면은 `ADM-번호`, 공통 컴포넌트는 `C-번호` (7장).

## 2. 공통 틀

| 항목 | 모바일 (360px~) | 데스크톱 (1024px~) |
|---|---|---|
| 상단 | 로고(가칭 "로봇 습관") · 검색 · 알림 종 | 로고 · 메뉴 6개(홈·팩 찾기·커뮤니티·챌린지·배우기·내 공간) · 검색창 · 알림 · [+ 올리기] |
| 하단 | 탭 5개: 홈 · 팩 찾기 · [+] · 커뮤니티 · 내 공간 (S9) | 없음 |
| 본문 | 한 줄(1단) | 목록 화면은 왼쪽 필터 + 오른쪽 목록(2단), 상세 화면은 본문 + 오른쪽 요약 칸 |
| 시트 | 아래에서 올라오는 시트(C-13): 필터, [+], 신고, 권한 안내 | 가운데 창(모달) |
| 행동 버튼 | 화면 아래 고정(C-21): [설치하기], [해봤어요 쓰기] 등 | 오른쪽 요약 칸 안 |

**모든 화면의 공통 상태** (화면별 표에서는 다른 점만 적음)

| 상태 | 보이는 모습 |
|---|---|
| 불러오는 중 | 내용 자리에 회색 뼈대(스켈레톤) |
| 오류 | "연결이 불안정해요" + [다시 시도] |
| 권한 없음 | 권한 안내(C-17) 4종: 로그인 필요 / 로봇 등록 필요 / 보유 인증 필요 / 제작자만 |
| 빈 화면 | 빈 화면(C-18): 그림 + 한 줄 + 다음 행동 버튼 |

## 3. 화면별 명세

### SCR-01 홈 · P0

- **목적**: 들어오자마자 "내 로봇으로 오늘 할 것"을 보여 줌 (E6)
- **구성** (위 → 아래, 순서 고정 · 추천 알고리즘 없음)
  1. **시작 블록** — 상태에 따라 하나만 보임
     - 비로그인: 서비스 한 줄 소개 + [시작하기]
     - 로봇 미등록: "내 로봇을 등록하면 맞는 팩만 보여 드려요" + [내 로봇 등록]
     - 등록 후 첫 7일: "처음 산 날 해 볼 팩 5개" 모음(가로 스크롤 팩 카드)
     - 해봤어요 요청: 설치 기록이 있고 아직 안 쓴 팩 → "문워크 해 보셨나요?" + [해봤어요 쓰기]
  2. **이번 주 챌린지** 카드 → SCR-12
  3. **내 기종 인기 팩** (최근 30일 해봤어요 순, 가로 스크롤 5개 + [더 보기] → SCR-02)
  4. **내 기종 방 새 글** (3개 + [방으로] → SCR-09)
  5. **내 소식**: 내 팩에 달린 해봤어요·질문, 내 질문의 답 (최대 3개 + [알림 전체])
- **상태**: 비로그인은 2·3·4를 "전체 기종" 기준으로 보여 줌
- **데스크톱**: 2단 — 왼쪽 1·3·4, 오른쪽 2·5
- **관련**: E6, E4, C14, S4

├───────────────────────────┤

│            [해봤어요 쓰기] │

### SCR-02 팩 찾기 · P0

- **목적**: 내 로봇에 맞는 팩을 고름
- **구성**
  1. 종류 탭: **전체 · 행동 · 우리 집 규칙 · 안전 설정** (S1) — "묶음"은 전체에 섞여 배지로 구분
  2. 필터 줄(C-12): `[마이크로덕 v1.2 ✕]`(E2, 자동) `[난이도]` `[바닥]` `[시뮬 테스트 통과]` · 오른쪽 정렬 `인기 ▾`(인기 / 최신 / 성공률, C5)
  3. (필터를 바꾸지 않았을 때만) **모음** 가로 줄: 운영진 모음 카드 → SCR-14
  4. 팩 카드 목록(C-01, 세로)
- **동작**: 필터 버튼 → 필터 시트(모바일) / 왼쪽 고정 칸(데스크톱). "성공률" 정렬은 해봤어요 5건 이상인 팩만 나오고 안내 한 줄 표시 ("해봤어요 5건 이상인 팩만 보여요")
- **상태**
  - 결과 없음: "이 조건에 맞는 팩이 아직 없어요" + [필터 줄이기] + (제작자면) [팩 올리기]
  - 내 기종 팩이 0개: "마이크로덕 팩이 아직 없어요. 다른 기종 팩도 볼까요?" + [모든 기종 보기]
- **관련**: S1, E1, E2, E4, C5, S4

### SCR-03 팩 상세 · P0

- **목적**: "이 팩, 우리 집에서 되나?"를 한 페이지에서 판단하고 설치
- **상단 요약** (모든 탭 공통)
  - 이름 · 버전 · 종류 배지(C-03) · 기종·펌웨어 범위 · 난이도
  - 숫자 표시(C-02): 건수 모드 `해봤어요 3 · 성공 2` / 비율 모드 `성공률 96% (46/48) · 넘어짐 4%` + 시뮬 표시 `시뮬 테스트 100회 · 넘어짐 3` 또는 `시뮬 테스트 준비 중`
  - 만든 사람(C-25) · 원작(변형일 때) · 변형 N개
  - 경고 띠(C-16, 있을 때만): "확인 중 — 위험 신고가 들어와 운영진이 보고 있어요" / (2단계) "이 버전은 넘어짐이 늘었다는 보고가 많아요"
  - 30초 영상(C-19)
  - [찜] [공유] [⋯ 신고]
  - **하단 고정**: [설치하기] — 내 로봇과 호환되지 않으면 비활성 + "마이크로덕 v1.2 이상에서만 돼요"
- **탭** (S10): `소개 · 해봤어요(N) · 질문·문제(N) · 버전 · 변형(N)` — 변형 탭은 1개 이상일 때만

| 탭 | 구성 (위 → 아래) | 빈 상태 |
|---|---|---|
| **소개** (03a) | ① **주의 상자**(C-15): 한계와 위험 체크 항목 + 서술 (A4) ② 한 줄 소개·설명 ③ 설치 정보: 설치 자리·동작 종류 (S11 보충) ④ **설치 순서**(C-24, 번호 단계, A3) ⑤ 잘 되는 바닥 / 안 되는 바닥 ⑥ 필요한 다른 팩 (있을 때) ⑦ 출처: 라이선스 · 원본 위치 링크 · 영어 원문 링크 ⑧ 면책 문구 한 줄 (F6) | — (필수 칸이라 비지 않음) |
| **해봤어요** (03b) | ① 요약: 숫자 표시 + 바닥별 성공 (마루 20/20 · 카펫 6/8 …) ② 필터 칩: [내 바닥만] [실패만] [영상 있는 것] · 버전 선택 ③ 해봤어요 카드(C-20b) 목록 — 실패도 숨기지 않음 ④ [해봤어요 쓰기] | "아직 해본 사람이 없어요. 첫 번째로 해 보고 알려 주세요" + [해봤어요 쓰기] |
| **질문·문제** (03c) | ① 고정 질문 최대 3개 (제작자 지정, C9) ② 필터: [전체/질문/문제] [열림/해결됨] ③ 글 행(C-20a) 목록: 종류·상태 배지 ④ [질문하기] [문제 알리기] | "아직 질문이 없어요" + 두 버튼 |
| **버전** (03d) | 버전 행: 버전 번호 · 날짜 · 바뀐 점 한 줄 · 그 버전의 숫자 표시 · (2단계) 위험 버전 표시. 맨 위가 최신 | — |
| **변형** (03e) | 변형 팩 카드 목록 · (규칙·안전 팩일 때) [복사해서 내 버전 만들기] (A7) | 탭 자체를 숨김 |

- **데스크톱**: 본문(탭) + 오른쪽 요약 칸(숫자·설치하기·만든 사람 고정)
- **관련**: S3, S4, S10, A3~A10, B1, B7, C9, F1, F6

### SCR-04 설치하기 흐름 · P0

- **목적**: 안전하게 공식 설치 경로로 넘겨주고, 설치 기록을 남김. 우리 서비스는 직접 설치하지 않음 (S8, A6)
- **단계**

```
[설치하기] 누름
  → (비로그인) SCR-22 로그인        → (로봇 미등록) SCR-18 등록
  → (첫 설치 1회만) 면책 동의 시트 (F6)
  → ① 설치 전 확인 시트
       "이 팩을 깔면 걷기 자리의 지금 동작이 바뀌어요" (설치 자리)
       설치할 버전: v1.3  ·  [되돌리는 방법 보기] → SCR-13 해당 글
  → ② 기종별 다음 단계 안내 (C-24)
       마이크로덕: 공식 안내 페이지 열기 + (고급) 설치 명령 복사
       Reachy Mini: "Reachy Mini Control 앱 > Discover Apps에서 '○○'을 찾으세요" + 앱 페이지 링크
       그 밖의 기종: 원본 위치 열기
  → 설치 기록 저장 (팩·버전·리비전·날짜) → 내 공간 '설치 기록'
  → 토스트: "설치하고 나면 해봤어요로 알려 주세요"
  → 다음 방문 때 홈 시작 블록 / 알림으로 해봤어요 요청
```

- **상태**: 호환 안 됨 → [설치하기] 비활성 + 이유 / 확인 중 경고 띠가 있는 팩 → 확인 시트에 경고 한 줄 추가 (설치는 막지 않음)
- **확인 필요**: 마이크로덕 일반 사용자용 설치 화면(공식 앱·playground)의 정확한 경로 — Phase 0에서 실제 로봇으로 확인 후 문구 확정
- **관련**: S8, A6, F6, H15, evidence 3-3

### SCR-05 해봤어요 쓰기 · P0

- **목적**: 3번 탭으로 결과를 남김 (S3)
- **들어오는 길**: 팩 상세 해봤어요 탭, 홈 요청 블록, [+] 시트, 알림
- **권한**: 보유 인증 회원 이상 (S12). 아니면 C-17 "보유 인증을 받으면 해봤어요를 쓸 수 있어요" + [인증하기]
- **구성** (한 화면, 위 → 아래)
  1. 팩·버전 (설치 기록의 최신 버전 자동, [바꾸기])
  2. **결과** (필수, 큰 버튼 3개): 성공 / 일부 성공 / 실패
  3. **넘어짐** (필수): 없었어요 / 있었어요
  4. 바닥 (내 로봇 정보로 자동, [바꾸기])
  5. 한 줄 소감 (선택, 100자)
  6. 영상 (선택, 60초 이하) → SCR-25
  7. (이 팩이 이번 주 챌린지면) [챌린지 참가로 표시] 체크 (기본 켜짐)
  8. [올리기]
- **올린 뒤**: 성공이면 "내 기종 방에도 자랑할까요?" [자랑 글로 올리기] / 실패면 "문제를 알려 주면 제작자가 고칠 수 있어요" [문제 알리기]
- **관련**: S3, S4, S12, C14, F5, F7

### SCR-06 질문하기 · 문제 알리기 · P0

- **목적**: 팩에 관한 질문·문제를 정해진 칸으로 받음 (S6)
- **구성**
  1. 종류 선택: [질문하기] [문제 알리기]
  2. **글쓰기 전 안내** (F8): 질문 → "로봇 기종·펌웨어·바닥을 적으면 답이 빨라요" / 문제 → "언제, 어떻게 됐는지 영상이 있으면 가장 좋아요"
  3. 제목 → 입력하면 아래에 **비슷한 글 3개** (C19): "이미 답이 있을 수 있어요"
  4. 본문
  5. (문제 알리기만, 필수) 로봇·펌웨어·버전(자동) · 바닥 · 어떤 일이 있었나 · 영상(선택 → SCR-25)
  6. [올리기]
- **관련**: S6, C9, C10, C19, F8

### SCR-20 팩 올리기 마법사 · P0 (제작자)

- **진행 표시** n/8 (C-14), 중간 저장 가능

| 단계 | 내용 |
|---|---|
| 1. 원본 | **행동 팩**: 원본 주소 붙여넣기 → 허용 목록 검사(B6) → **자동 채움 결과 표시** (기종·동작 종류·설치 자리·라이선스·최신 리비전, S8 개정) · **규칙·안전 팩**: "내용 직접 쓰기" 선택 |
| 2. 기본 | 이름 · 한 줄 소개 · 종류 (자동 채움, 수정 가능) |
| 3. 호환 | 기종 · 펌웨어 범위 · 설치 자리·동작 종류(자동) · 필요한 다른 팩(선택) |
| 4. 난이도·환경 | 설치 난이도 · 사용 연령 · 잘 되는 바닥 / 안 되는 바닥 |
| 5. 이야기 | 설명 · **설치 순서 단계**(추가/순서 바꾸기, 단계마다 사진·영상) · 30초 영상 |
| 6. 한계와 위험 | 체크리스트 5개 + 그 밖의 주의 (필수, A4) |
| 7. 출처 | 라이선스(목록, A10) · 원작 팩(변형일 때) |
| 8. 확인 | 팩 상세 미리 보기 → [제출] |

- **규칙·안전 팩의 "내용 직접 쓰기"**: 규칙 문장 목록("현관 앞은 가지 마") + 설정값 표(이름 · 값 · 단위, 예: 최고 속도 · 0.3 · m/s) + "로봇에 적용하는 방법" 설명
- **제출 후**: 첫 팩 → "운영진이 확인하고 있어요" / 이후 → 바로 공개 + (행동 팩·지원 기종) "시뮬 테스트 중"
- **새 버전 올리기**: 버전 번호 · 바뀐 점 한 줄(필수) · 리비전(자동). 공개한 버전은 고칠 수 없다는 안내 (A5)
- **관련**: S8, S11, A2, A4, A5, A10, A12, B1, B6

## 5. 핵심 흐름 3개 — 끊기는 곳 점검

| 흐름 | 단계 | 끊길 수 있는 곳 → 대응 |
|---|---|---|
| **처음 온 소유자** | 홈 → 로봇 등록 → 처음 산 날 모음 → 팩 상세 → 설치하기 → (공식 경로) → 해봤어요 | 펌웨어를 모름 → "모르겠어요" 안내 / 설치 후 돌아오지 않음 → 홈·알림 해봤어요 요청 / 보유 인증 없음 → 해봤어요 앞에서 인증 안내 |
