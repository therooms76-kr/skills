## 판단 기준 (모든 기능에 같은 잣대)

사업계획서의 세 원칙을 그대로 잣대로 씁니다.

1. **로봇 회사와 싸우지 않는다** — 파일 보관·실행은 남(허깅페이스 등)에게 맡기고, 우리는 찾기·고르기·믿기·설치하기·자랑하기만 한다.
2. **일반인이 5분 안에 성공해야 한다** — 개발자에게만 쉬운 기능은 숨기거나 뒤로 미룬다.
3. **경험은 파일이 아니라 이야기다** — 후기·영상·이름 붙이기를 돕는 기능은 점수를 더 준다.

여기에 하나를 더합니다.

4. **사람이 적을 때도 돌아가야 한다** — 초기 사용자는 수백 명 규모(사업계획서 Phase 0 기준 100명)입니다. 사람이 많아야 의미가 생기는 기능(투표 정렬, 순위표 등)은 뒤로 미룹니다.
