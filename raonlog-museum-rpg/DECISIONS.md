## 결정에서 바로 나오는 다음 행동

1. **T1 테스트 페이지** (`t1-test/index.html`): 1부 프로토타입 + 관람 여권(도장·발견·등급·꾸미기 보상)을 한 방으로 합친 페이지.
   공유 카드는 G1의 판단 재료이므로 실험용으로 포함. 끝에 설문 3문항 + '결과 코드' 생성. 지인이 코드를 돌려보내면 집계.
2. **사용자가 할 일**: 고양이 스프라이트(4방향 또는 2방향), 지인 20명 링크 발송, 라온로그 비공개 저장소 생성(E5),
   claude.ai/code 환경에 Custom 허용 목록 환경 생성(E1).
3. **T1 합격선**: 액자 3개 이상 연 사람 60%↑, "다시 오고 싶다" 3.5/5↑, 공유 카드 만든 사람 30%↑(→ G1 c 채택 기준).
4. T1 통과 시: A트랙 1단계(방 하나 실전) + B트랙 B1(문법 사전·소장품 목록) 병행.

## 측정 방식에 대한 메모

지인에게 보내는 페이지는 외부 공개 링크라 서버 저장(db)을 붙일 수 없다. 페이지가 브라우저 안에서 행동을 세고,
설문 끝에 짧은 '결과 코드'(예: `RAON-T1B|h3|o5|s3|f1|c1|e4|r4|h0|t312`)를 만들어 준다. 지인이 코드를 카톡으로 보내면
`t1-test/tally.md`의 표에 옮겨 적어 합격선과 비교한다.

## 개정 제안 · 디자인 방향 B (2026-09-26)

사용자 의견: "국립중앙박물관에서처럼 실제 박물관을 들어가서 관람하는 형태의 디자인".
대응: 입구 → 역사의 길(좌우로 걷는 긴 복도, 화강암 바닥, 끝에 경천사탑) → 전시실(어두운 벽, 스포트라이트, 흰 명판, 벤치)
→ 사유의 방(검은 방, 별 천장, 한 점, 명판·버튼 없음, 잠시 서 있으면 고양이가 앉음)의 동선을 그대로 옮긴 B안 프로토타입 제작.
- 바뀌는 결정: D2만. D1·D3·D5~D8, E, G는 그대로 B안 위에 얹는다.
- 그릴 것: 배경 3종(복도·전시실·사유의 방). 게임 엔진 불필요(D8 유지).
- 캐릭터: 복도는 좌·우 2방향으로 충분, 전시실용 앞·뒤가 있으면 좋음.
- 사용자 확인(2026-09-26): B안 확정 + 세 가지 추가 요청(정면 원근 복도, 유리 진열장, 실제 사진 배경) 반영 → v2.
- T1 테스트 페이지는 v2로 교체 (`t1-test/index.html`). A안 픽셀 방 버전은 `t1-test/index-a-pixel.html`로 보관.
- 사진 배경: 이 환경에서는 외부 사진을 받을 수 없고 박물관 사진은 저작권 확인이 필요하므로, 가족이 직접 찍은 사진 3장(복도 정면, 전시실 벽, 사유의 방)을 `PHOTOS` 설정에 넣는 방식으로 준비. 소실점(vx, vy)만 맞추면 문이 사진에 붙는다.
