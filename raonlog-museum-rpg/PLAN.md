## 0. 한눈에 보기

- **무엇을 만드나**: 블로그 첫 화면이 박물관 로비가 된다. 고양이를 움직여 5개의 전시실(카테고리)에 들어가면
  벽에 걸린 액자가 곧 블로그 글이다. 액자 앞에 서면 명판(제목·날짜·한 줄 요약)이 보이고, 클릭하면 글을 읽는다.
  글 안에서 옆 액자로 넘기거나 이어지는 글로 건너뛴다.
- **왜 박물관인가**: 박물관은 "많은 것 중 무엇을 어떤 순서로 볼지"를 오래 다듬어 온 공간이다.
  관람객의 고민(너무 넓다, 뭘 봐야 할지 모르겠다)과 해법(대표작, 추천 코스, 명판)이 블로그 방문자와 같다.
- **지금 결정할 것**: 5장의 D1~D8.

## 1. 국립중앙박물관 관람 행태 분석

> 조사 방식 안내: 이 세션의 네트워크 정책이 박물관 공식 사이트, 트립어드바이저, 네이버, 위키 등 외부 접근을
> 모두 차단해 실시간 후기 수집은 하지 못했다. 아래 7가지 패턴은 학습된 범위에서 널리 반복되는 관람 후기와
> 박물관 관람 행동 연구를 바탕으로 정리한 것이다. 9장에 직접 확인할 근거 5개를 두었다.

| # | 관람객 목소리 (요약) | 박물관의 대응 | 블로그로 옮기면 |
|---|---|---|---|
| 1 | 너무 넓어서 다 못 봤다. 두 시간 지나니 지친다. | 1시간·2시간 추천 코스, 층별 안내도, 대표 유물 위주 배치 | 방마다 액자 6~8개만. 나머지는 수장고(전체 목록). 첫 방문자용 30분 코스 |
| 2 | 1층 '역사의 길'을 따라 걸으면 길을 잃지 않는다. | 건물 중앙을 관통하는 큰 복도, 양옆으로 전시실 분기 | 로비 = 최근 글 순서의 긴 복도. 복도 양옆 문이 5개 카테고리 방 |
| 3 | '사유의 방' 하나 보러 갔다. 어두운 방에 두 점만 있는데 제일 기억에 남는다. | 대표작 1~2점에 방 하나를 주는 몰입형 특별실 | 사유의 방 = 이달의 글 또는 가장 아끼는 글 1편만 걸린 어두운 방 |
| 4 | 아이랑 가면 어린이박물관·실감영상관이 최고. 만지고 움직여야 아이가 버틴다. | 예약제 어린이박물관, 실감영상관 | 라온이 방에 만지면 반응하는 소품. 액자에 가까이 가면 살짝 들썩임 |
| 5 | 명판과 오디오 가이드 번호, 도슨트 해설 덕에 이해가 됐다. | 모든 유물에 명판, 번호형 오디오 가이드, 도슨트 투어 | 액자마다 명판(제목·날짜·카테고리·한 줄 요약). 도슨트 코스 = 큐레이션 시리즈 |
| 6 | 경천사 석탑 앞, 사유의 방은 사진 찍기 좋다. 카페에서 쉬었다. | 포토 스팟과 휴게 공간을 동선 중간에 배치 | 글 보기 화면에 공유 버튼. 로비 한쪽 카페 = 소개·방명록 |
| 7 | 같은 시대·재료의 유물이 연결돼 보이면 재밌다. 온라인 소장품의 '관련 유물'이 유용했다. | 전시 동선의 시대 연결, 온라인 소장품의 관련 소장품 추천 | 글 사이 연결(같은 나들이·장소·등장인물)을 눈에 보이게. 4장 |

한 줄 요약: 관람객은 "다 보기"를 포기하고 "대표작 + 추천 코스 + 명판"에 기댄다. 블로그도 '모든 글 목록' 대신
'방마다 몇 개의 액자 + 명판 + 이어지는 글'로 보여 주면 같은 효과가 난다.

박물관 행동 연구에서 자주 인용되는 사실 3가지:
1. 박물관 피로: 관람 30~45분 후 유물당 머무는 시간이 눈에 띄게 짧아진다. → 방당 액자 수 제한.
2. 우회전 경향: 입장 후 많은 사람이 오른쪽으로 먼저 돈다. → 로비 오른쪽 첫 문에 가장 보여 주고 싶은 방.
3. 출구 끌림: 출구가 보이면 남은 전시를 건너뛴다. → 글 보기 화면에서 '닫기'보다 '다음 전시'를 크게.

## 2. 공간 구조

카테고리 5개 = 방 5개. 여기에 박물관에서 배운 세 공간을 더한다.

```
                 [라온이의 방]   [나들이 방]     [맛집 방]
                 Korean         Family          Food &
                 Parenting      Adventures      Dining
                     |              |               |
[입구/홈] ===== 로비 복도 (최근 글이 시간순으로 걸린 긴 벽) ===== [사유의 방: 대표 글 1편]
   |                 |              |               |
 [카페]          [건강 방]     [메시의 방]      [수장고]
 소개·방명록     Health &       Life with       전체 글 목록·검색
                 Wellness       Messi           (게임을 건너뛰는 출구)
```

- 로비 복도: 길을 잃는 문제를 푼다.
- 사유의 방: 뭐가 제일 좋은지 모르는 문제를 푼다.
- 수장고: 게임이 싫은 방문자의 문제를 푼다.

## 4. 콘텐츠 연결 표현 (제안)

### 연결 규칙 4가지 (글 프런트매터에 적는 정보)

| 규칙 | 뜻 | 정보 | 예 |
|---|---|---|---|
| 같은 나들이 | 같은 날 같은 외출에서 나온 글 | `trip: 2026-09-05-museum` | 박물관 글 ↔ 칼국수 글 |
| 같은 장소 | 다른 날, 같은 곳 | `place: 국립중앙박물관` | 봄 방문 ↔ 가을 방문 |
| 같은 등장인물 | 라온이·슌님·메시 중심 | `people: [raon, messi]` | 메시 글 ↔ 라온이가 메시 돌본 글 |
| 같은 주제 태그 | 계절, 음식 종류, 시리즈 | `tags: [autumn, noodles]` | 막국수 ↔ 칼국수 |

### 보여 주는 방식 3가지

- **A. 명판 아래 '이어 보기'** (추천, 필수): 글 보기 화면 아래 연결 글 3개를 카드로, 연결 이유를 작게 표시.
  박물관 온라인 소장품의 '관련 소장품'과 같다. 프로토타입에 구현됨.
- **B. 방 사이의 '연결 문'** (추천, 2단계): 한 나들이가 두 방에 걸치면 두 방 사이 벽에 작은 문.
  문 위 명판에 "박물관 가는 날 점심으로 이어짐". 고양이가 문으로 지나가면 다른 방의 해당 액자 앞에 도착.
- **C. 털실 자취** (후순위, 재미 요소): 고양이가 지나간 길이 털실처럼 바닥에 남고 방문한 액자끼리 실로 이어진다.
  프로토타입 토글로 켤 수 있다.

## 5. 결정 지점 8개

답은 "D1은 c, D2는 추천대로" 식으로 짧게.

### D1. 게임 화면과 일반 블로그 화면의 관계 (가장 큰 결정)
- a. 게임만: 몰입 최고. 검색엔진이 글을 못 읽고 모바일이 힘듦.
- b. 게임은 입구, 글은 일반 페이지: 검색·모바일·접근성 문제 없음. 게임→글 전환이 끊김.
- c. 게임 안에서 미리보기(명판 확대)까지, '전체 읽기'는 일반 페이지. 게임을 끄는 수장고 모드 포함.
- **추천 c.** 박물관의 "유물 앞에 서기 → 명판 읽기 → 더 알아보기" 3단계와 같다.
- 확인 질문: 구글 검색 유입이 있는가? 있으면 a 제외.

### D2. 카메라 시점
- a. 3/4 위에서 본 시점(포켓몬·스타듀밸리): 뒷벽에 액자, 바닥 자유 이동. 캐릭터 4방향.
- b. 옆에서 본 시점(횡스크롤): 좌우 이동만. 캐릭터 2방향(하나 그리고 뒤집기).
- c. 아이소메트릭(동물의 숲): 가장 예쁘지만 모든 소품을 비스듬히 다시 그림. 캐릭터 4~8방향.
- **추천 a.** 캐릭터를 2방향만 그릴 계획이면 b가 현실적.
- 확인 질문: 고양이 캐릭터를 몇 방향으로 그릴 수 있는가?

### D3. 움직이는 방법
- a. 키보드만 / b. 탭한 곳으로 걸어가기 / c. b + 키보드 옵션
- **추천 c.** 걷는 시간은 0.6초를 넘기지 않는다.

### D4. 방의 구성
- a. 5개 방만 / b. 로비 + 5개 방 / c. 로비 + 5개 방 + 사유의 방 + 수장고 + 카페
- **추천 c, 단 순서를 둔다.** 1단계 방 하나 → 2단계 로비+5개 방 → 3단계 특별실·수장고·카페.

### D5. 액자를 클릭했을 때
- a. 바로 글 페이지로 / b. 방 안에서 확대 창(사진·제목·요약·이전/다음·이어 보기) 후 '전체 읽기'
- **추천 b.** '다음 액자' 버튼을 '닫기'보다 크게(출구 끌림 대응).

### D6. 연결 표현 방식
- **추천 A 필수 + B 2단계 + C 보류.**
- 확인 질문: 기존 글 맨 위에 연결 정보를 채워 넣는 것을 허락하는가? (본문은 건드리지 않음)

### D7. 고양이 캐릭터의 역할
- a. 방문자 = 고양이(조종) / b. 고양이 = 도슨트(안내) / c. a + 액자 앞에서 한 줄 말풍선
- **추천 c.** 캐릭터가 메시라면 자기 방에서 캣타워에 오르는 특별 동작 하나.
- 확인 질문: 캐릭터가 메시인가, 별도의 고양이인가?

### D8. 만드는 방법 (기술)
- a. 게임 엔진(Phaser 등) / b. 일반 웹 기술(HTML·CSS·JS, 프로토타입 방식)
- **추천 b.** 이동과 클릭이 전부라 엔진이 필요 없다. 방 정보는 JSON 하나, 글 정보는 기존 글에서 자동 생성.
- 확인 질문: 라온로그가 어떤 도구(Next.js, Astro, Hugo 등)로 만들어졌고 어디에 배포되는가? 글은 마크다운인가?

## 8. 용어 카드

- 스프라이트: 게임 캐릭터 그림 한 장. 걷기는 여러 장을 빠르게 바꿔 보여 준다.
- 3/4 시점: 위에서 비스듬히 내려다본 화면. 뒷벽과 바닥이 같이 보인다.
- 명판: 유물 옆 설명판. 여기서는 액자 아래 제목·날짜·한 줄 요약.
- 프런트매터: 글 파일 맨 위 정보 칸(제목, 날짜, 태그).
- 박물관 피로: 관람 30~45분 후 집중이 떨어지는 현상.
- 수장고: 전시하지 않는 소장품 창고. 여기서는 게임 없이 보는 전체 글 목록.
- 접근성: 키보드만 쓰는 사람, 화면 읽어 주는 프로그램 사용자도 쓸 수 있게 만드는 것.
- 검색 유입(SEO): 구글이 글을 읽고 검색 결과에 띄우는 것.
