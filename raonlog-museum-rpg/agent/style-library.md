# 문법 사전 (style-library) v0.1

박물관이 사물 하나를 소개하는 "말하는 방식"을 모아 둔 파일. 루틴이 매주 한 줄씩 더한다.
형식만 적는다. 박물관의 문장, 유물 이름, 전시 내용은 적지 않는다.

형식: `- [출처] 형식 이름 — 구조 — 라온로그에 옮기면`

- [국립중앙박물관] 큐레이터 추천 소장품 — 유물 1점 / 왜 골랐는지 한 문단 / 눈여겨볼 곳 — Curator's Pick: 우리 집 물건 1개, 왜 이 물건이 우리 집 역사에서 중요한지
- [공통] 명판(유물 라벨) — 명칭 / 시대 / 재질 / 크기 / 출토지 / 소장 경위 — Object Label: 모든 글 아래 자동 명판 (title, date, material, provenance, credit line)
- [국립중앙박물관] 특별전 개막 보도자료 — 주제 한 문장 / 기간·장소 / 대표 유물 3점 / 기획 의도 — Special Exhibition: 기존 글 3~6편을 주제로 다시 묶은 기획전, 개막 안내문
- [국립중앙박물관 박물관신문] 이달의 유물 — 유물 하나를 깊게, 만들어진 배경과 지금의 위치 — Object of the Month: 사진 한 장의 앞뒤 이야기
- [국립중앙박물관 사유의 방] 한 점 몰입 — 어두운 방, 최소 설명 — Quiet Room: 사진 1장, 50단어, 설명하지 않기
- [영국박물관 블로그] 보존 처리 이야기 — 훼손 상태 / 처리 과정 / 전후 비교 — Conservation Notes: 뜯긴 소파, 자전거 수리, 깨진 그릇
- [공통] 신소장품 공개 — "새로 들어온 유물" 예고 / 입수 경위 — New Acquisition: 새 사진 폴더가 생기면 자동 예고, 본문은 가족이
- [국립중앙박물관] 큐레이터와의 대화 — 정해진 요일·시간, 전시실 앞 30분 문답 — Docent Talk: 글 1편을 라온이 질문 5개로, 수요일 18시 이후에만 열림
- [메트 Family Guide / MetKids] 가족 활동지 — 그림 속에서 찾기 / 세어 보기 / 다음에 할 것 — Family Guide: 액자 옆 놀이 카드

- [공통 뉴스레터] What's On — 새 전시 / 행사 / 관람 팁 / 다음 달 예고 — This Month at the Raonlog Museum: 우리 박물관 소식지
