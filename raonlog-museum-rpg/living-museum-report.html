스스로 자라는
라온로그 살아있는 박물관

1부(고양이 박물관 계획)에 이어, 두 가지를 보고합니다. 첫째, 해외 커뮤니티와 국내 블로그·커뮤니티까지 넓혀 다시 모은 관람객 의견. 둘째, 국립중앙박물관과 해외 유명 박물관의 새 소식·전시·프로그램을 매주 자동으로 모아 블로그 콘텐츠를 만드는 에이전트와, 그 콘텐츠가 게임 속 박물관을 매주 바꿔 놓는 ‘살아있는 체험’ 계획입니다.

한눈에 보기

의견 재조사 결과

해외(트립어드바이저·여행 가이드·레딧 요약 사이트)와 국내(티스토리·다모앙·디시·서브스택·서울시 미디어허브)를 합쳐 14개 출처, 20여 개 의견을 모았습니다. 1부의 7가지 패턴이 그대로 확인됐고, 새 패턴 2개(“사유의 방은 사진 줄 때문에 사유가 안 된다”, “추천 동선을 그대로 따라가면 망한다”)가 추가됐습니다.

매주 수집 에이전트

국립중앙박물관은 월간 박물관신문, 보도자료, 매주 수요일 큐레이터와의 대화, 특별전 일정, 교육플랫폼 ‘모두’를 정기적으로 냅니다. 해외는 메트·클리블랜드·시카고·레이크스·스미스소니언이 공개 데이터 통로(API)를 엽니다. 이걸 매주 한 번 읽어 “이번 주 박물관” 글을 초안으로 만드는 루틴을 제안합니다.

살아있는 체험

자동으로 만든 글이 게임 속 ‘이번 주 전시실’에 새 액자로 걸리고, 수요일·토요일 밤에는 박물관처럼 야간 개장 조명이 켜지고, 해외 박물관에서 ‘대여 온 유물’이 걸립니다. 방문할 때마다 조금씩 달라지는 박물관입니다.

솔직한 한계 두 가지. ① 이 세션은 웹 ‘검색’은 되지만 웹 페이지를 ‘직접 여는 것’은 모두 차단되어(박물관 사이트, 레딧, 티스토리, 해외 박물관 API 전부) 의견은 검색 요약과 요약 사이트를 통해 모았습니다. 원문 링크를 9장에 두었습니다. ② 같은 이유로 매주 수집 에이전트도 지금 환경 설정으로는 돌 수 없습니다. 환경의 네트워크 설정을 바꾸면 됩니다(7장 E1). 이것이 이번 보고에서 가장 먼저 정할 일입니다.

03 · 매주 수집 에이전트

‘메시 도슨트’ 루틴: 매주 한 번 박물관을 돌고 와서 초안을 쓴다

Claude Code에는 루틴(Routine)이라는 기능이 있습니다. 정해진 시각에 클라우드에서 세션을 하나 열어, 저장된 지시문대로 일하고, 결과를 GitHub 브랜치에 올립니다. 노트북을 꺼 놓아도 돕니다. 이 루틴 하나로 아래 파이프라인을 매주 월요일 아침에 돌리는 것을 제안합니다.

루틴 지시문 초안 (저장소에 함께 넣었습니다)

루틴은 지시문이 전부입니다. 아래는 핵심만 추린 것이고, 전체 초안은 저장소의 raonlog-museum-rpg/agent/weekly-museum-watch.prompt.md에 있습니다. 통로 목록은 agent/sources.yaml로 분리해 두어, 박물관을 추가하거나 빼는 일이 파일 한 줄 편집으로 끝납니다.

역할: 라온로그의 도슨트 고양이 ‘메시’. 매주 월요일 박물관 소식을 돌아보고
      허킹 가족(아빠·슌님·7세 라온이) 관점으로 영어 블로그 초안을 쓴다.

1. sources.yaml의 통로를 순서대로 읽는다. 실패한 통로는 건너뛰고 보고서에 남긴다.
2. agent/state/seen.json과 비교해 ‘새로 생긴 것’만 남긴다.
3. 각 항목에 가족 점수(0~5)를 매긴다: 무료 여부, 7세 적합, 예약 필요, 기간 임박, 야간 개장.
4. 초안 3종을 만든다: This Week at the Museum(주 1편), Object of the Week(주 1편),
   Family Calendar(월 1회, 매월 첫 월요일). 문체는 raonlog-blog-writer 스킬을 따른다.
5. 사실은 반드시 출처 링크와 함께 쓰고, 확인 못 한 것은 “(to verify)”로 표시한다.
6. content/auto/ 아래에 마크다운으로 저장하고 claude/weekly-museum-YYYY-MM-DD 브랜치에
   푸시한 뒤 초안 PR을 연다. PR 본문에 ‘이번 주 새로 생긴 것 목록’과 실패한 통로를 적는다.
7. seen.json을 갱신한다. 절대 하지 않을 것: 예약 잔여석 긁기, 이미지 무단 저장, 자동 게시.

어디서 돌릴 것인가 (세 가지 방법 비교)

10 · 용어 카드

이 문서에 나온 말 풀이

루틴(Routine)정해진 시각에 클라우드에서 Claude Code 세션을 자동으로 여는 예약 작업. 노트북이 꺼져 있어도 돈다.
API사람이 보는 웹 페이지 대신, 프로그램이 읽기 좋게 데이터를 내주는 창구. 메트·클리블랜드가 이런 창구를 공개한다.
RSS새 글이 올라오면 제목·링크·날짜만 모아 주는 구독 형식. 영국박물관 블로그가 제공.
CC0“저작권을 포기했으니 마음대로 쓰세요”라는 표시. 메트·클리블랜드·시카고의 공개 이미지가 이것.
공공누리한국 공공기관 저작물의 이용 조건 표시. 1유형이면 출처만 밝히고 자유롭게, 2~4유형은 상업 이용이나 변경에 제한.
허용 목록(allowlist)“이 주소들만 갈 수 있다”는 명단. 세션 환경의 Custom 설정이 이것.
seen.json지난주까지 본 것들의 목록 파일. 이게 있어야 ‘새로 생긴 것’만 골라낼 수 있다.
초안 PR글을 바로 올리지 않고 “이렇게 쓸까요?” 하고 내미는 제안서. 사람이 승인하면 올라간다.
프런트매터글 파일 맨 위의 정보 칸. 자동 글에는 source, verified, trip 같은 꼬리표가 붙는다.
북극성 지표이 자동화가 성공했는지를 재는 단 하나의 숫자. 여기서는 ‘예고 글이 실제 방문으로 이어진 횟수’.
